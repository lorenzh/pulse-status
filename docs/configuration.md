# Configuration

pulse-status reads these environment variables, all in `src/main.ts`. It has no config file other than the optional theme file.

| Env                                | Default                 | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ---------------------------------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PORT`                             | `8080`                  | Port of the status server                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `PULSE_API_URL`                    | `http://localhost:3000` | pulse-api base URL. `/api/*` on this server is proxied to it                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `POLL_MS`                          | `5000`                  | Integer from 1000 to 2147483647. Page refresh interval in ms                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `PULSE_STATUS_THEME`               | none                    | Path to a JSON theme file, see [theming.md](theming.md#theme-file)                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `PULSE_STATUS_NAME`                | `pulse`                 | Product name, 1 to 60 characters, see [theming.md](theming.md#name-and-logo)                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `PULSE_STATUS_LOGO`                | none                    | Logo file or `https://` URL, see [theming.md](theming.md#name-and-logo)                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `PULSE_STATUS_PUBLIC_URL`          | none                    | Public `http(s)` URL of the status page, without credentials, query or fragment. Turns on `/feed.atom`, see [Feed and badges](operation.md#feed-and-badges)                                                                                                                                                                                                                                                                                                                                       |
| `PULSE_STATUS_HIDE_DETAILS`        | `true`                  | `true`, `false`, `1` or `0`. Hides check targets, keywords, heartbeat period and grace, and reasons. While checks are hidden behind components, incident reasons are hidden with either value, see [What is public](operation.md#what-is-public)                                                                                                                                                                                                                                                  |
| `PULSE_STATUS_SHOW_CHECKS`         | `false`                 | `true`, `false`, `1` or `0`. With components configured, lists the member checks under each component and checks that belong to none, each HTTP check with its own latency chart. With `false` and components, no check name or id is served, and each component with HTTP member checks gets one latency chart (highest member check), see [Latency and availability](operation.md#latency-and-availability). Lists have no effect without components, see [Components](operation.md#components) |
| `PULSE_STATUS_CACHE_MS`            | `2000`                  | Integer >= 0. How long the proxy reuses an answer, errors included, and the stored render of the page. `0` turns the caches off, see [Caching](operation.md#caching)                                                                                                                                                                                                                                                                                                                              |
| `PULSE_STATUS_UPSTREAM_TIMEOUT_MS` | `4000`                  | Integer from 1 to 2147481647. Time limit for one request to pulse-api, headers and body                                                                                                                                                                                                                                                                                                                                                                                                           |
| `PULSE_LOG_LEVEL`                  | `info`                  | `debug`, `info`, `warn` or `error`, see [Log format](operation.md#log-format)                                                                                                                                                                                                                                                                                                                                                                                                                     |

`PORT` is an integer from 0 to 65535 and `POLL_MS` an integer from 1000 to 2147483647 (`POLL_MS: must be an integer from 1000 to 2147483647`). `PULSE_STATUS_LOGO` must not be an `http://` URL (`PULSE_STATUS_LOGO: URL must use https`). An invalid value stops the server at start with exit code 2. `PULSE_STATUS_PUBLIC_URL` that is not an `http(s)` URL, or has credentials, a query or a fragment, stops the server at start (`PULSE_STATUS_PUBLIC_URL: must be ...`); a trailing slash is removed. An empty `PULSE_STATUS_PUBLIC_URL`,`PULSE_STATUS_THEME`, `PULSE_STATUS_NAME`, `PULSE_STATUS_LOGO` or `PULSE_STATUS_HIDE_DETAILS` counts as not set. An empty `PULSE_STATUS_SHOW_CHECKS` counts as not set. Any other value of `PULSE_STATUS_HIDE_DETAILS` or `PULSE_STATUS_SHOW_CHECKS`, and a `PULSE_STATUS_CACHE_MS` or `PULSE_STATUS_UPSTREAM_TIMEOUT_MS` that is not an integer in range, stops the server at start. `PULSE_STATUS_UPSTREAM_TIMEOUT_MS` is an integer from 1 to 2147481647 (`PULSE_STATUS_UPSTREAM_TIMEOUT_MS: must be an integer from 1 to 2147481647`): the page adds 2000 ms, and a browser timer holds at most 2147483647 ms. Keep `PULSE_STATUS_CACHE_MS` below `POLL_MS`, so each poll sees fresh data.

`PORT` and `POLL_MS` are parsed as plain integers: values such as `1e3` or `5000ms` stop the server at start.

Example:

```sh
PORT=9000 PULSE_API_URL=http://api.internal:3000 POLL_MS=10000 bun start
```

A trailing `/` in `PULSE_API_URL` is removed. An invalid theme file, name or logo stops the server at start. See [troubleshooting.md](troubleshooting.md).

The server reads the theme file once, at start, and checks at start that the logo file exists. Restart the server after you change the theme file, the name or the logo path. A logo file is read again on each request to `/logo`.
